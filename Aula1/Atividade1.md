# Software para venda de perfumes

### Qual o objetivo inicial ? 
 <u>Criar um aplicativo web para vendas e controle de perfumes.</u>

 ### Qual problema vamos resolver com a criação desse Software?

 <u>O software vai resolver o problema do cliente precisar sempre se deslocar a alguma loja fisica para realizar compras e agora com o software vai passar a comprar produtos de casa de forma online.</u>

### Qual o escopo inicial planejado? 
<u>Entregar um aplicativo web funcional que entregue desde administração, venda e entrega de perfumes.</u>
