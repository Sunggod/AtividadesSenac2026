# <u> Site web Loja de produtos gerais </u>

__Requisitos Funcionais:__
*1-* Login
*2-* Registro
*3-* Carrinho de compras
*4-* Chat de atendimento ao cliente

__Requisitos Não Funcionais:__ 
*1-* Banco de dados
*2-* Documentação técnica 
*3-* Suporte para telas mobiles
*4-* Diagramas de todas tabelas do banco de dados
*5-* Testes automatizados e manuais
*6-* Manutenção corretiva e evolutiva 
*7-* Monitoramento continuo da infraestrutura do sistema (infra)


#### Objetivo Inicial
<u>Criar um site para venda de produtos de forma online e prática para que assim resolver um problema local onde os clientes de uma loja física tenham opção de comprar e receber em casa seu produto.</u>
